
推送成功。接下来在 GitHub 网页上做三件事：

------------------------------------------------------------------
第 1 件：开启 Actions 写权限（不做这步，定时更新会失败）
------------------------------------------------------------------
  仓库页面 → Settings → 左侧 Actions → General
  拉到最下面 Workflow permissions
  选 Read and write permissions → 点 Save

------------------------------------------------------------------
第 2 件：开启 GitHub Pages
------------------------------------------------------------------
  仓库页面 → Settings → 左侧 Pages
  Source 选 Deploy from a branch
  Branch 选 main，目录选 /docs → 点 Save

------------------------------------------------------------------
第 3 件：手动跑一次
------------------------------------------------------------------
  仓库页面 → Actions 标签 → 左侧点「更新 RSS 源」
  → 右侧 Run workflow → 绿色按钮

  等大约一分钟，它会抓完十个源，并把结果提交回仓库。

------------------------------------------------------------------
完成后
------------------------------------------------------------------
  打开你的订阅中心（把下面的「你的用户名」换成你自己的）：

      https://你的用户名.github.io/energy-rss/

  页面上每个源都有「在 Inoreader 订阅」按钮，点一下就直接加进去。

  想一次性全加：下载
      https://你的用户名.github.io/energy-rss/subscribe.opml
  然后在 Inoreader 里进「设置 → 导入 → 从文件」。

  页面每个源下面还有一行状态，写着上次抓到内容的时间和条数。
  如果某个源一直显示没抓到过，说明 GitHub 那台机器被这个网站拦了，
  这时改用 run_local.bat 在你本机跑。

注意：GitHub Pages 第一次部署要一两分钟才生效，刚点完打不开是正常的。
